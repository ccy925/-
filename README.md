# 《小食神大富翁：六大類食物大作戰》課堂指南

## 🎲 棋盤格子黃金比例（16 格配置）

* **🎯 答題區（約 80%）**：11 格。
  * 踩中立即觸發「直觀圖片 2 選 1」或「10秒快速打地鼠」。
  * **答對才送食材**！答錯無食材，直接回棋盤。
* **❓ 機會區（約 10%）**：2 格（第 4、12 格）。
  * 幸運好習慣事件（如：多喝白開水、跑步精神好），**免費抽得 1 份食材**或前進。
* **⚡ 命運區（約 10%）**：2 格（第 8、15 格）。
  * 與壞習慣/陷阱相關（如：偷吃炸物薯條退後 2 格、喝高糖汽水退後 1 格、熬夜暫停 1 回合）。
  * **命運區絕不給食材**。
* **🚩 起點 / 廚房**：1 格（第 0 格）。
  * 跑完一圈回起點，集齊該圈食材即可開火翻炒做料理！
